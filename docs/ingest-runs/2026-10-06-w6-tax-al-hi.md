## Method

1. Held already? Every row was matched against the local corpus root (all inventories' `source_url` /
   `download_url` and every provisions `citation_path` of the ten jurisdictions, including the unreleased wave-4/5
   scopes) and, for statute and regulation rows, by section number. Scopes committed on main only as lock files
   (`.axiom/corpus-locks/<jur>/<class>/<version>.json`) count as held: every locked source file's sha256 (all
   jurisdictions) was compared with every source file of the new scopes, the seven locked scopes of these
   jurisdictions whose bytes are not on the local disk were listed, and the signed ingest manifests
   (`.axiom/ingest-manifests/`) were searched for the May 2026 manifests behind the EXTRACT-MANIFEST rows. One
   duplicate came out (after the first extraction, corrected): `manifests/us-ca-2025-ftb-3514-booklet.yaml` was
   extracted on 2026-09-23 (c643c9ec6) into the locked `us-ca/form/2026-09-23-ca-2025-ftb-3514` (same PDF, same
   path `us-ca/form/individual-income-tax/2025/3514-instructions`); row 206 is ALREADY-HELD there and the document
   was dropped from the new CA forms scope. Mirror and vendor rows (Justia, FindLaw,
   LegiScan, Lexis) were resolved to their section through the title PolicyEngine gives the reference
   (`policyengine-us` 84253b6, read offline as a checklist only) and then looked up in the held scopes.
2. One plain GET per remaining address with the corpus user agent and the extractor's own Accept headers (one
   request at a time per host, hosts in parallel; TLS verified against certifi plus `data/certs`), body read: PDF
   page 1 (printed title, tax year, revision) or HTML title; the result is recorded in each manifest entry as
   `first_page_first_line`. Viewer and wrapper addresses (ADOR UltraViewer, ADOR form landing page, DOR
   FillableForms viewer) were resolved to the PDF they frame; third-party reposts (taxformfinder, taxsim,
   zillionforms, DocHub) to the publisher's own file of the same edition.
3. `scripts/build_w6_tax_al_hi_manifests.py` holds the static tables (one entry per document, with the work-order
   rows it answers) and writes one manifest per jurisdiction, class and family:
   `manifests/us-xx-income-tax-w6-{forms,guidance,legislation}.yaml`, version `2026-10-06-w6-income-tax-<family>-<xx>`
   (`forms` = class `form`, `guidance` = `guidance`, `legislation` = `statute`). `--decisions` writes the decisions
   file and checks every PRESENT / ALREADY-HELD path against the provisions on disk (and, for the D.C. title-47 rows,
   against the scope on the open PR #753 branch); `--queue` writes the queue rows.
4. Extraction: `extract-official-documents` per manifest (PDF forms and booklets `single_block`, the convention of
   the 2026-09-10 and 2026-09-15 state-forms runs; the C.R.S. editions, the Colorado Constitution and the two CT public acts one row per page; HTML one row per heading);
   the ALISON Title 16 scope through `extract-state-statutes` (`manifests/us-al-income-tax-w6-statute-title-16.yaml`).

Citation paths follow `us-xx/form/<agency>/ty<year>/<id>` (agencies `ador`, `dfa`, `azdor`, `ftb`, `cdor`, `drs`,
`otr`, `dor`, `dotax` as in the held forms scopes), `us-xx/guidance/<publisher>/<id>`,
`us-xx/statute/session-laws/<session>/<act>` (the CO and GA precedent) and `us-xx/statute/bills/<session>/<bill>`.
The May 2026 EXTRACT-MANIFEST entries of `us-az-individual-income-tax-forms.yaml`, `us-ca-official-forms.yaml`,
`us-ct-individual-income-tax-forms.yaml` and `us-hi-individual-income-tax-forms.yaml` carry paths with underscore
segments (`us-az/form/individual_income_tax_forms/azdor.gov/...`), which the citation-path grammar rejects. Those
documents keep the manifest's path with the slug rule applied (`citation_segment` on every hierarchy segment, the
convention of the wave-6 tax-ok-wv run): `us-az/form/individual_income_tax_forms/azdor.gov/sites/default/files/2023-03/forms_individual_2021_140`
becomes `us-az/form/individual-income-tax-forms/azdor.gov/sites/default/files/2023-03/forms-individual-2021-140`.
Each manifest entry records `may_2026_manifest_path`, and each of the 79 decisions rows maps the bundle path to the
new path. The three `us-ca/form/ftb/2024/...` paths of `us-ca-ftb-2024-tax-instructions.yaml` are grammar-valid and
were kept.
