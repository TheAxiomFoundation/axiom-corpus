# 26 USC 63 provenance repair and 26 USC 165 ingest

Release selector `us-2026-07-27-usc-63-repair-165` adds a source-faithful
successor scope for 26 U.S.C. §§ 63 and 165. It does not alter the historical
immutable scopes that contain the defective §63 provenance.

## Defect repaired

The existing normalized §63 text is correct, but both current copies cite the
House reader URL for §45A and resolve through inventory to a retained
177,385-byte XHTML file with SHA-256
`ce8b0ed86616c74c2b3926b516b5c42a8f7419157e4623ee9d05c392764c546e`.
Those bytes identify `26 USC 45A: Indian employment credit` and contain no
`Taxable income defined` text. The old inventory therefore attests a different
statute, not merely an imprecise filename.

This successor normalizes §63 from exact retained official USLM bytes and uses
the section-specific reader URL:

`https://uscode.house.gov/view.xhtml?req=granuleid:USC-prelim-title26-section63&num=0&edition=prelim`

## Retained official source

The source is the immutable OLRC Title 26 download current through Public Law
119-102, except 119-101, as of 2026-07-12:

- URL:
  `https://uscode.house.gov/download/releasepoints/us/pl/119/102not101/xml_usc26@119-102not101.zip`
- ZIP: 8,289,527 bytes; SHA-256
  `d405deff27cc0d05566100b852feff5f5a125fb81c6dd2896092f0262c9dbec0`
- Sole `usc26.xml` member: 55,856,053 bytes; SHA-256
  `d2f67de8052e9e2a96e3da34d84cbe2d677bc1b5840e8fa0e79cbfa7e9b28621`

The reproduction script verifies both hashes and proves the retained XML is
byte-equal to the ZIP member before extraction. It copies the already-retained
official bytes; it does not reconstruct, reserialize, or hand-edit a source
snapshot.

## Reproduction

The five corpus artifacts in this scope—OLRC ZIP, exact XML member, inventory,
provisions, and coverage—are reproduced by this literal command:

```bash
uv run --extra dev python scripts/repro/us_63_repair_165.py --base data/corpus
```

The script invokes the scoped extractor with the equivalent arguments:

```bash
uv run --extra dev axiom-corpus-ingest extract-usc \
  --base data/corpus \
  --version 2026-07-27-usc-63-repair-165 \
  --source-xml data/corpus/sources/us/statute/2026-07-27-usc-63-repair-165-title-26/uslm/usc26.xml \
  --title 26 \
  --source-as-of 2026-07-12 \
  --expression-date 2026-07-12 \
  --source-url https://uscode.house.gov/download/releasepoints/us/pl/119/102not101/xml_usc26@119-102not101.zip \
  --section 63 \
  --section 165 \
  --include-title
```

## Result

Coverage is complete at 163/163 rows: one self-contained Title 26 row, 62
§63 rows, and 100 §165 rows. Publisher identifiers support every descendant
through subclause depth. The §63 body is unchanged from the previously
normalized text, including the source's note following §63(b)(6); no apparent
statutory error was edited.

Section 165 has unique operative identifiers and does not exercise the
duplicate-number sibling or mixed/formal-part traversal cases fixed in #523.
The current collision-aware traversal therefore needs no new parser change.

No publication, R2 upload, Supabase load, RuleSpec change, push, or release
activation is part of this ingest.
