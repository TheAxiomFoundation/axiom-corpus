## Method

1. **Held already?** Every row was checked against an index of every `us` scope on the controller's disk: the 296
   locked scopes (read from the git blobs their `.axiom/corpus-locks/us/*/*.json` files name when the bytes are not
   local) and the unsigned local scopes of waves 3-5. The index holds every citation path, every URL in provision and
   inventory metadata (`source_url`, `download_url`, `print_version_pdf`, ...) and every source file's sha256. A row is
   ALREADY-HELD when its path (or, for section-family references such as `26 CFR 1.1411`, the family's sections) is a
   row of a scope, when its address is the source or print version of a held document of the same edition, or when the
   bytes the publisher served today are byte-identical to a held source file (AL-23-0026-RIM2, Schedules D and SE 2025).
   After the controller's mid-run note (locked scopes count as held, including their source file names and the
   manifests that produced them), the check was widened to every jurisdiction: the sha256 and file name of every
   source in all 1,906 lock files, every URL in every locked inventory (read from its git blob) and every manifest on
   `main`. It found four more held documents (state-plan SPAs in `us-nv`, `us-ri` and `us-ga` scopes, Family 4); they
   were dropped from the manifest and their scope re-extracted. No manifest on `main` lists any other new document.
2. **One probe per address** with the corpus client (`requests`, the extractor's user agent and headers, TLS verified
   against certifi), one request at a time per host, before any manifest was written: status, final URL, size,
   sha256, and the printed title, edition and date read from page 1 of every PDF (or the HTML title). Probe caches stayed
   in the session scratch directory.
3. **Manifests from one generator.** `scripts/build_w6_federal_manifests.py` holds every document in static tables
   (address, printed title, edition, date, extraction options) and writes nine manifests, one scope each. `source_url`
   is the bundle's address whenever that address was fetched (the bundle generator joins by URL); where the bundle
   names a mirror, a bot wall or a dead address, the official alternative is `source_url` and the bundle address is
   recorded in `metadata.bundle_addresses` and joined through the decisions row.
4. **Extraction** with `extract-official-documents` (documents), `inventory-ecfr` + `extract-ecfr` (CFR) and
   `extract-usc` (U.S. Code), one family per process, families grouped so that no two processes fetched the same host
   at the same time. Coverage was read back for every scope, and every document checked for text (no document without
   a non-empty row; printed years of all 70 IRS products matched the citation path).
5. **Decisions** from `scripts/build_w6_federal_decisions.py`, which re-verifies every PRESENT and ALREADY-HELD row
   (the cited path must be a row of the cited scope; PRESENT scopes must report coverage `complete: true`) before
   writing the CSV.
