# USITC HTS 2025 revision snapshots, part 3

This source-first run retains eleven full-revision USITC Harmonized Tariff
Schedule (HTS) JSON snapshots, Revisions 22 through 32 of the 2025 edition.
Each version normalizes chapters 72, 76, and 95 plus every `9903` heading in
chapter 99 at citation paths `us/statute/hts/{htsno}`.

## Scope

official USITC static source bytes. Every source came from the exact Internet
Archive Wayback `id_` capture URL recorded in its corpus metadata. The same
metadata records whether the archived response body was gzip-encoded, the
Yale cover date, and the independent mirror verification against
`yale-budget-lab/tariff-rate-tracker:data/hts_archives/hts_2025_rev_{N}.json.gz`.

## Verification

Reproduce this scope from the verified local inputs with:

```bash
uv run --extra dev python scripts/repro/us_hts_tariff_snapshots_2025_part3.py \
  --base data/corpus \
  --source-dir ~/.axiom/workspace/laneA-hts-downloads
```

Before parsing, the script checks the SHA-256 and byte size of every input. It
then builds all source, inventory, provision, and coverage artifacts in a
temporary staging directory and verifies them before copying them into the
requested base. Verification covers total and target row counts, the complete
chapter breakdown, duplicate HTS numbers and citation paths, byte equality of
the retained source, complete inventory/provision path equality, complete
coverage, and every provision's version, expression date, official source URL,
exact Wayback download URL, and source provenance metadata.

The generated-body anchors assert in every revision that
`us/statute/hts/7202.11.10.00` contains both “Containing by weight more than 2
percent but not more than 4 percent of carbon” and the general rate `1.4%`.
They also assert that `us/statute/hts/9903.01.25` carries the applicable duty
plus 10 percent, while `us/statute/hts/9903.03.01` is absent from every 2025
snapshot. Each coverage report is complete and contains one document root in
addition to the target-row count shown above.
