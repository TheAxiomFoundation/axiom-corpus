# USITC HTS 2025 revisions 11–21 ingest

This source-first scope retains eleven full-revision USITC Harmonized Tariff
Schedule JSON snapshots from the 2025 edition. Each source is an Internet
Archive Wayback Machine capture of its official USITC static URL and is pinned
byte-for-byte. The normalized provisions cover chapters 72, 76, and 95 plus
every `9903.*` heading, all under the shared citation root
`us/statute/hts/{htsno}`.

## Scope

artifacts for each version: the retained source, source inventory, normalized
provision JSONL, and coverage report.

The `expression_date` values are the USITC `releaseStartDate` values. Source
metadata retains the Yale cover date separately. Every capture is
byte-identical after gunzip to the named mirror in
`yale-budget-lab/tariff-rate-tracker` at
`data/hts_archives/hts_2025_rev_{N}.json.gz`; each metadata record carries the
mirror path and gunzip SHA-256. The download provenance did not record
`wayback_body_gzip` for Revision 12, so its value is explicitly `null` rather
than inferred. The final download URLs use the exact Wayback `id_` form.

## Verification

Reproduction command:

```bash
uv run --extra dev python \
  scripts/repro/us_hts_tariff_snapshots_2025_part2.py \
  --base data/corpus \
  --source-dir ~/.axiom/workspace/laneA-hts-downloads
```

The script verifies each input's SHA-256 and byte size, builds all outputs in
a temporary staging directory, and checks the source bytes, total and target
row counts, chapter breakdown, HTS-number uniqueness, version,
`expression_date`, official `source_url`, exact Wayback download URL, source
provenance metadata, inventory/provision path equality, and coverage fields
before writing to `data/corpus`.

All eleven coverage reports are complete, covering 18,104 inventory and
provision rows including one document root per snapshot. The body checks
assert `Rates of duty (1-General): 1.4%` on `7202.11.10.00` and
`The duty provided in the applicable subheading + 10%` on `9903.01.25` in
every revision. The absence check confirms that section 122 heading
`9903.03.01` does not occur in any of the eleven 2025 snapshots.

## Downstream

These versioned HTS expressions extend the primary comparison surface for the
US tariff parity campaign without changing the shared citation root. They are
inputs for downstream RuleSpec encoding and tariff oracle comparisons; this
ingest run does not publish a corpus release or load the serving database.
