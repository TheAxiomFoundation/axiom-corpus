# 26 USC 469 passive-activity and material-participation source

The focused scope `2026-08-29-usc-469-title-26` adds the complete official
26 U.S.C. §469 hierarchy needed to derive the passive-activity predicate used
by §1411 without treating material participation as a QBI predicate under
§199A.

## Result and boundary

Coverage is complete at 164/164 rows: one title, one section, 12 subsections,
53 paragraphs, 59 subparagraphs, 33 clauses, and five subclauses. Including
the Title 26 root makes the immutable ingest scope self-contained. The release
does not add that scope alongside the existing Title 26 carrier. Instead it
consolidates the prior Title 26 union and this scope, preferring the prior
carrier for the duplicate root, then replaces the old union with the
collision-free successor:

```bash
uv run --extra dev python scripts/consolidate_release_scopes.py \
  --base data/corpus \
  --jurisdiction us \
  --document-class statute \
  --source-version 2026-08-03-rulespec-title-26-current-union \
  --source-version 2026-08-29-usc-469-title-26 \
  --target-version 2026-08-29-rulespec-title-26-with-469-union \
  --prefer-duplicate-carrier \
    us/statute/26=2026-08-03-rulespec-title-26-current-union
```

The operative source includes §469(c)(1), which defines a passive activity as
a trade or business in which the taxpayer does not materially participate,
and §469(h), which defines and qualifies material participation. This corpus
work supplies legal text only; executable QBI and NIIT classification remains
in `rulespec-us`.

The citation-path grammar's `uppercase_segments` ratchet is deliberately
raised from 7,007 to 7,104. The 97 new unique paths are the official uppercase
US Code subparagraph and subclause labels within §469; immutable copies in the
consolidated successor are counted once by the validator.
