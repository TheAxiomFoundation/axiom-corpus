# USITC HTS 2025 snapshots, part 1

This source-first scope retains the 2025 Harmonized Tariff Schedule (HTS)
Basic Edition and Revisions 1–10 for the US tariff parity campaign. The
snapshots cover the early-2025 sequence through the first appearance of the
IEEPA reciprocal-tariff heading `9903.01.25`.

## Scope

The reproducer is
`scripts/repro/us_hts_tariff_snapshots_2025_part1.py`. Each source is an
Internet Archive Wayback Machine `id_` capture of its official USITC static
JSON URL. The exact capture bytes are retained under `data/corpus/sources`.
All 11 captures have `wayback_body_gzip=true` and are byte-identical after
gunzip to the named files in
`yale-budget-lab/tariff-rate-tracker/data/hts_archives`.

The corpus versions are
`2026-08-01-usitc-hts-2025-basic` and
`2026-08-01-usitc-hts-2025-rev1` through
`2026-08-01-usitc-hts-2025-rev10`. Citation paths remain
`us/statute/hts/{htsno}`; the version distinguishes each expression.

Normalized provisions include all rows whose HTS number begins with `72`,
`76`, `95`, or `9903`. Row bodies retain descriptions, units, duty-rate
columns, additional duties, quotas, and footnotes. Metadata retains the raw
row fields and indent-derived ancestor chain. Each source record also retains
the official URL, exact Wayback `id_` URL and timestamp, capture gzip flag,
Yale cover date, mirror repository and path, gunzip SHA-256, byte-equality
outcome, and mirror-verification statement.

## Verification

Run from the repository root:

```bash
uv run --extra dev python scripts/repro/us_hts_tariff_snapshots_2025_part1.py \
  --base data/corpus \
  --source-dir /Users/maxghenis/.axiom/workspace/laneA-hts-downloads
```

The script verifies every input SHA-256 and byte size before parsing, builds
all artifacts in a temporary staging directory, and only then writes the
verified files into `data/corpus`. For every snapshot it checks the full
source-row count, target-row count, chapter breakdown, unique HTS numbers,
byte-equal retained source, unique citation paths, per-row version,
expression date and official source URL, complete provenance metadata,
inventory/provision path equality, and complete coverage.

The body anchors are derived from the retained rows. All 11 snapshots contain
`us/statute/hts/7202.11.10.00` with `Rates of duty (1-General): 1.4%`.
Heading `us/statute/hts/9903.01.25` is absent from the Basic Edition through
Revision 6, then present with
`The duty provided in the applicable subheading + 10%` in Revisions 7–10.
Heading `us/statute/hts/9903.03.01` is absent from every snapshot in this
slice. Coverage includes the document root, so each coverage count is one
higher than the target-row count shown in the table.

## Downstream

These versioned HTS rows provide the early-2025 tariff expressions used by
the `rulespec-us` tariff encodings and the `us_tariff` oracle suite in
`axiom-oracles`. They extend the existing T0 snapshot surface without adding
new citation-path families or changing release state.
