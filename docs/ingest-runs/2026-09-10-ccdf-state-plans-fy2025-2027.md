## Source and index inventory

("FY 2025-2027 State/Territory CCDF Plans", HHS Administration for Children and Families,
Office of Child Care; publication date 2024-12-19, "current as of" 2026-04-24). The lead-list URL

## Extraction

The plans are CARS (Child Care Automated Reporting System) "ACF-118 FFY2025-2027 CCDF Plan Print
Template" PDFs (Aspose.Words export; PDF title carries that string) with the same 10 sections
and 41 second-level subsections in every jurisdiction. Provision unit: one provision per
subsection (1.1 ... 10.2) plus the document root = 42 per plan. `labeled_sections`, heading
`^(?P<label>\d{1,2}\.[1-9])\s+(?P<heading>[A-Z]\S.*)$` (the single non-zero digit after the dot
keeps rate-table lines such as "94.00 Per" and "1.0 Strict." out), `start_after_pattern ^Overview$`
(skips the OMB notice and the table of contents on pages 1-3), page headers/footers dropped,
`heading_continuation_pattern` so the wrapped 2.4 heading is complete. Section 10.2 absorbs the
trailing "Appendix 1" template pages; sub-subsections (1.1.1, 5.3.10, ...) stay inside their
parent body. Smoke jurisdictions: OK and WV (42/42, unique), then the pattern was re-run over all
25 downloaded candidates before the full run (41 sections each, canonical order, no duplicates).

Variants:

- California posts its own Word export, not the CARS print: labels mostly sit alone on a line
  with the heading on the next line. `label_only_heading_pattern` + `label_only_requires_heading`.
- Illinois publishes the plan only as an HTML page (h3 headings; `#ItemContentDiv`, TOC dropped).
  List items such as "1.2 Sliding fee scale" also start with a label, so the heading is required to
  be one of the 41 preprint headings; `stop_text_pattern` at "Appendix 1: Lead Agency
  Implementation Plan".
- Alabama's PDF is prefixed with the ACF approval letter (301 pages); the pattern is unaffected.
- Wyoming's Lead Agency page links the plan on Google Drive; fetched through the extractor's
  existing Google Drive download path.
- FL, MA, MI, NH return HTTP 403 to plain `requests`; their manifests set
  `request: browser_impersonation: true` (existing option).

TLS: dese.ade.arkansas.gov (AR) serves only its leaf certificate (issuer Sectigo Public Server
Authentication CA OV R36, root Sectigo Public Server Authentication Root R46).
`data/certs/sectigo-public-server-authentication-ca-ov-r36.pem` is that public intermediate,
fetched from the leaf's AIA URL (http://crt.sectigo.com/SectigoPublicServerAuthenticationCAOVR36.crt).
Extraction ran with `REQUESTS_CA_BUNDLE` = certifi + that file
(`data/certs/ccdf-ca-bundle.pem`, generated, ignored). Verification was not disabled anywhere.

## Reviewer judgments

1. Family boundary: the ACF index hosts only the Appendix PDFs; the plans are Lead Agency
   publications reached through the index. The plan was taken as the primary source
   (source_authority names both ACF-118 and the Lead Agency publisher); the 51 ACF-hosted
   Appendices are inventoried and left as a separate family.
2. Version choice: the initially approved plan where the publisher posts it (17 jurisdictions);
   where only an amended consolidated plan is posted, that plan (AR Amendment 2, GU Amendment 1,
   IA Amendment 1, MI Amendment 2, the last also having Amendment 1 posted); where the state
   posts the certified submission rather than an approval print (NH, SD, WA), that version.
   Separately posted amendment approval letters and later consolidated amendments (CA, DC, MA,
   NC, ND, OH, SD, WA) were not taken. expression_date stays 2024-10-01 for all.
3. Provision granularity: 41 subsections + root, not the 10 top-level sections and not the
   third-level questions.
4. Illinois as HTML with a heading whitelist; California with the label-only variant.
5. Wyoming fetched from Google Drive because that is where the Lead Agency page links the plan.
6. Wisconsin's file is named `...plan-draft-10-2024.pdf` but its content is the approved print
   (Plan Status "Approved as of 2024-11-09"); taken as the approved plan.
7. The 25 blocked jurisdictions: recorded as publisher blocks with exact failures; the agent did
   not use proxies, VPNs, or cached copies.
8. IN, ME, MS, PA, PR, VI: no crawl beyond the index-linked page; a reviewer may locate the plan
   elsewhere on those sites.
9. GitNexus impact analysis was not run because the tools were unavailable in this session; no
   existing function was modified (new script only, no adapter code).
