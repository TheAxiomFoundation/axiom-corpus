# Ingest run: USITC HTS notes for 2026 Revisions 3, 4, 12 (parity gap close)

Date: 2026-08-02 (UTC). Follow-up to the 44-release notes gapfill
(`2026-08-01-usitc-hts-notes-gapfill.md`).

## Why

The 44-release notes gapfill scoped itself to the releases whose full
snapshots were still missing from the corpus, plus the T0-ingested 2026
Revision 14. That framing silently skipped 2026 Revisions 3, 4, and 12:
their snapshots were already on `main` from the T0 run (axiom-corpus#557),
so they were not "remaining" for snapshots — but no notes versions existed
for them anywhere. This run closes that three-release hole; with it, every
release in the parity window (2025 Basic + Revisions 1–32, 2026 Basic +
Revisions 1–14) has a per-revision General Note 3 and Chapter 99 notes
version.
