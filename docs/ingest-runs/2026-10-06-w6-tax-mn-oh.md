## Method

1. **Held already?** Every row was searched against the local corpus root before any extraction: the bundle
   address and its redirect target against every inventory `source_url`/`download_url` of the twelve jurisdictions,
   the bundle path and its ancestors against every provision `citation_path`, statute rows by section number against
   the held chapter scopes, and (after the controller's correction) the scope lock files on main
   (`.axiom/corpus-locks/<jur>/<class>/<version>.json`, whose bytes are not in the local root) by source sha256. Every
   extracted source was also hashed against every held and locked source of the same jurisdictions: the only match was
   the NY IT-214/IT-214-I pair (locked `us-ny/form/2026-09-23-ny-it-214-ty2025`), which was dropped from the new NY
   forms scope (`-r2`) and recorded ALREADY-HELD. No two new documents share bytes.
2. **Probe.** Every official address was fetched once (one thread per host, one request at a time per host, 1 s
   spacing) with the corpus user agent; PDFs were read with `pdftotext` (page count, first-page lines, printed year,
   PDF modification date), HTML pages for title and content root. Third-party rows (taxsim.nber.org,
   taxformfinder.org, zillionforms.com, LegiScan, Justia, Cornell, public.law) were not ingested; the zillionforms file
   was opened once to identify it (the 2021 Montana Form 2 instructions) and deleted.
3. **Manifests.** `scripts/build_w6_tax_mn_oh_manifests.py` holds the table of documents (each with the work-order
   ids it closes) and writes one manifest per jurisdiction and family, `manifests/us-xx-income-tax-w6-{forms,guidance,
   statute}.yaml`, version `2026-10-06-w6-income-tax-<family>-<st>`; `source_url` is the bundle address wherever that
   address served the document (`download_url` only where the publisher redirects to a file host). `--decisions`
   writes the decisions CSV, `--queue` the queue rows.
4. **Extraction.** `extract-official-documents` per manifest, three host-disjoint batches in parallel, PDFs
   `single_block` (root + `document-1`, no page rows: the local `page_n` and `block_n` counts are already above the
   ratchet baselines), HTML pages one block per heading under an explicit `html_content_selector`. New Jersey Title 54
   through the `new-jersey-statutes` adapter (`manifests/state-income-tax-w6-tax-mn-oh-statutes.yaml`).
5. **Checks.** Every scope `complete: true`, 0 missing, 0 extra, 0 duplicate citation paths;
   `scripts/validate_citation_paths.py` on the 32 scopes: 3,157 records, 3,157 unique paths, `RESULT: OK` (block_n 531,
   page_n 0, uppercase 11 = Minn. Stat. 270C.22); no path collides with any pre-existing local scope or with the 59
   other wave-6 scopes on disk in these jurisdictions at 20:05; every manifest entry matches its inventory item
   (source URL, title, bundle rows); every PRESENT/ALREADY-HELD row's path exists in the scope it names.

Citation paths: forms `us-xx/form/<agency>/ty<year>/<id>` (agencies as in the wave-4/5 scopes: department-of-revenue,
dor, mtdor, ncdor, otc, dra, taxation, trd, tax, odt); department pages and publications `us-xx/guidance/<agency>/
<slug>` (with `ty<year>` when year-specific); statute sections in each state's existing form (`us-mo/statute/135.010`,
`us-mn/statute/270C.22`, `us-nc/statute/105/105-153.10`); superseded statute versions with the `--` variant joiner
(`us-mo/statute/135.010--effective-2008-08-28`, `us-mt/statute/15-30-2131--mca-2019`); enacted bills
`us-xx/statute/session-laws/<year or GA>/<bill>`; bill versions and bill-information pages `us-xx/statute/bills/...`.
The May 2026 tax-forms manifest paths (`us-mo|us-nd|us-oh/form/individual_income_tax_forms/<host>/...`) contain
underscores and host segments the citation-path grammar rejects; each was re-slugged to the convention above and the
decisions file maps every old bundle path to its new path.
