## Method

1. **Held already?** Before any extraction every row was matched against the local corpus root: the bundle address and
   the triage's final address against every inventory `source_url` / `download_url` of the six jurisdictions (scheme,
   `www.` and case folded), the bundle path against every provisions `citation_path`, the identifiers in each address
   (form ids, KRS and Pa. Code section numbers, the bill number) against every inventory entry, and each fetched file's
   sha256 against every inventory and every lock file under `.axiom/corpus-locks/` (every locked scope of the six
   jurisdictions is on the local disk). Then the open pull requests: #753 (named by the brief) and every other open
   axiom-corpus PR's file list for scopes of these jurisdictions and classes. Two open PRs hold six of the rows: #753 and
   #754. The sibling wave-7 work orders (`federal`, `state-benefits`, `rejoin`) name none of these documents.
2. **Probe.** One GET per address with the corpus user agent and the extractor's Accept headers, all addresses in one
   sequential loop (so never two requests at a time to any host, 1.5 s spacing per host), TLS verified against certifi
   plus the committed `data/certs/` intermediates. Every PDF's page 1 (printed form number, revision, tax year), page
   count and control-character count were read with `pdftotext`; every HTML page's title and text. Eleven bundle
   addresses, the two D.C. booklets (to compare with PR #753), and three State Budget Portal addresses for the
   Virginia row.
3. **Manifests.** One official-documents manifest per jurisdiction and class, written by hand (eight documents did
   not need a generator): `manifests/us-in-income-tax-w7-forms.yaml` (version `2026-10-12-w7-income-tax-forms-in`) and
   `manifests/us-va-income-tax-w7-statute.yaml` (version `2026-10-12-w7-income-tax-statute-va`). `source_url` is the
   bundle address exactly, query included, for every FETCH row taken; the Virginia row's official address differs from
   the bundle's LegiScan address and joins through its decisions row.
4. **Extract and check.** `extract-official-documents` per manifest; coverage `complete: true`, 0 missing, 0 extra,
   0 duplicate citation paths; every source file inventoried with its sha256 equal to the probe's;
   `scripts/validate_citation_paths.py` over the new provisions files: 811 records, 811 unique paths, `RESULT: OK`
   (`page_n` 800, no other irregular family); no new path exists in any other provisions file of us-in or us-va on disk
   (all classes, including the other wave-7 agents' scopes); every PRESENT and ALREADY-HELD row's citation path was
   checked in the scope it names (local disk, or the PR branch through `git show`); the decisions file folds cleanly
   through `scripts/apply_wave_decisions.py` (run against a scratch output: 14 addresses joined to a path, 0 moves).

Citation paths follow the held scopes: Indiana forms `us-in/form/dor/ty<year>/<form>` (the TY2025 scope's
`us-in/form/dor/ty2025/it-40-booklet` shape), Virginia budget legislation `us-va/statute/budget/<year>/<bill>/...` (the
wave-6 `us-va/statute/budget/2026/hb30/...` shape), here `us-va/statute/budget/2025/hb1600/chapter-725` with one
`page-N` row per page.
