Asset Compatibility 510-05-70-17

(New 4/1/2023 ML #3712)

 

 

Below are the available electronic verification sources for asset compatibility

• AVS

• Motor vehicle (ND Verify-Motor Vehicle)

• Game and Fish (ND Verify-Game and Fish)

 

The total combined countable assets must be used to determine reasonable compatibility. If no asset information is returned from a data source and there are no known assets, asset compatibility can be determined.

 

  1. If reported assets and information obtained electronically through a data source are $500 or more below the asset limit for the Medicaid unit, it is asset compatible.

 

  1. Example - Individual with $3000 asset limit. The individual reports assets of $1500 in a checking account. Data source returns information indicating a checking account with $1000. Since both the reported assets and the data source returned are more than $500 below the asset limit, this would be considered asset compatible.

  2. Example - Individual with $3000 asset limit reports assets of $2700 in a checking account. Data source returns information indicating a checking account with $2800. Since the assets are within $500 of the limit the asset is not reasonably compatible.

 

  1. If reported data assets and information obtained electronically through a data source are more than the asset limit for the Medicaid unit, it is not asset compatible

 

Example- Couple with an asset limit of $6000 have reported assets of $7000. Data source returns assets of $8000. Both sources are over the asset limit. This would not be considered reasonably compatible. A review form and request for asset information will need to be sent out.
