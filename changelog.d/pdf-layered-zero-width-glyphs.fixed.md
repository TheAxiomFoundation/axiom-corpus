The opt-in PDF keys `amendment_markup` and `sort_blocks` now read the glyphs PyMuPDF's `rawdict` leaves out (a line whose box has no area and the last span of a line whose box has no area, which glyphs drawn with no width, such as a zero-advance period or a combining mark, make) on pages where leaving them out changes the text. Such a page used to stop extraction; it now extracts with the characters of the default text. Pages whose `rawdict` reading already matches the default text extract as before. PyMuPDF 1.26.6 or later is required.
