Kept the Israeli OpenLaw notes that state legal effect for a time window in the provision body even when they sit in running text. Two assumptions dropped them: that a note reaches a body only from a table cell or a terminating colon, and that a block whose only content is a note must be a repeal/expiry line. A note that names a temporary order, instructs a re-reading, or prints a `(qualifier: replacement)` substitution now reaches the body wherever it appears, and the note-only fallback is restricted to actual status markers.
