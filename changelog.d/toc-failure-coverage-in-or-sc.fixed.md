Keep an Indiana title, an Oregon chapter or a South Carolina title or chapter whose page cannot be fetched, is a maintenance, empty or wrong-shape page, or lists no children as an inventory gap with no provision, so coverage and strict release validation report the run as incomplete instead of reading it as complete. Before, the extractor logged such a container as an error and left it out of the inventory, and an Oregon chapter page with no chapter heading stopped the whole run. The gap points at the container's own page when the run fetched it but could not use it, and at the listing that names the container when the run could not fetch it: the South Carolina master index for a title, its title page for a chapter, and the Oregon landing page for a chapter. A South Carolina title page whose download fails no longer stops the run. A container empty by law stays complete, as before: a repealed Indiana title (IC 17 to 19), an Oregon chapter of former provisions, and a South Carolina chapter whose page notes it is repealed or reserved. A South Carolina chapter page that shows only its heading now reads as a gap. A run that writes no provision still raises, and a run with no failures writes the same artifacts as before.
