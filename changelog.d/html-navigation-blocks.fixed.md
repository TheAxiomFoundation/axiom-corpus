The official-document HTML extractor no longer writes a page's link lists as provision rows. A positional block (`block-N`, a WebWorks block or the whole-root fallback) is dropped when `content_quality.is_navigation_block` holds: the release content check's `navigation_body` rule, read against the retained page, with four more conditions (every token with a letter or digit inside a link or menu string, at least two such strings, none over 12 words, none ending a sentence), so a status line, a lone cross-reference, a figure beside a linked label, a definition inside a glossary link or a table of contents with amendment notes is kept for the check to report. A dropped block's ordinal is used up, so the blocks after it keep their citation paths. Manifests that declare their sections, HTML read out of JSON, pages the recovery batch re-encodes and manifests with `html_keep_navigation_blocks: true` are never filtered. Existing scopes do not change; `scripts/measure_html_navigation_blocks.py` re-extracts locked scopes offline to measure what a successor ingest would drop (`docs/ingest-runs/2026-10-13-html-navigation-blocks.md`).
