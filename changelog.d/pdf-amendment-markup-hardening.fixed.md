Harden the opt-in PDF keys `amendment_markup`, `sort_blocks` and `ignore_actual_text` (#741). The layered path no longer doubles a line's newline, and every layered page is checked against the default page text. `sort_text`, an empty `amendment_markup` mapping, non-integer or out-of-range page values and non-boolean `sort_blocks` or `ignore_actual_text` are rejected. Rules with zero opacity are ignored, and near-threshold and thick rules draw a `PdfAmendmentMarkupWarning`. A `typographic_underlines` phrase counts only where it is exactly an underlined stretch. `scripts/compare_pdf_amendment_markup_with_html.py` now compares labels word by word, so swapped labels fail.
