Send the NZ legislation API key on every request to legislation.govt.nz hosts, including the RSS feed, which now uses https. The key is added in the client's transport, one hop at a time: a hop carries it only when it is https to `legislation.govt.nz`, `www.legislation.govt.nz` or `api.legislation.govt.nz`, and it is removed from the request once that hop is sent. So a redirect off those hosts, or down to http, carries no key, and the key is not left on the response's request or on `next_request`. Changing or clearing the client's event hooks does not affect this. Requests the caller sends on the client without the key tag are left alone, and httpx still handles redirects, credentials and cookies as usual.
