Send the NZ legislation API key on every request to legislation.govt.nz hosts, including the RSS feed, which now uses https. The key stays with the client built with it: a request carries only a marker asking for the key, never the key itself, and the client's transport adds the key one hop at a time. A hop carries it only when it is https to `legislation.govt.nz`, `www.legislation.govt.nz` or `api.legislation.govt.nz`, and the `X-Api-Key` header is removed from the request once that hop is sent. So a redirect off those hosts, or down to http, carries no key. Changing or clearing the client's event hooks does not affect this. A key that is not printable ASCII without whitespace is rejected before any request is sent, with an error that does not include it. Requests the caller sends on the client without the marker are left alone, and httpx still handles redirects, credentials and cookies as usual.
