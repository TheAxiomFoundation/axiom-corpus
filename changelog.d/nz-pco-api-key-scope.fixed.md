Send the NZ legislation API key on every request to legislation.govt.nz hosts, including the RSS feed, which now uses https. The key goes only over https to those hosts: it is set on each such redirect hop and dropped from each request once sent, so no redirect inherits it. Each request carries its own wrapper's key, so wrappers sharing one httpx client each send their own key, the caller's other requests on that client are left alone, and httpx still handles redirects, credentials and cookies as usual.
