The official-documents PDF extractors accept `page_header_patterns`, which drop each page's running header by position: a page's k-th line is dropped when it matches the k-th pattern and every line above it was dropped. A bare page number can then be removed without also removing the same number printed as a table cell, which a `drop_line_patterns` entry such as `^\d{1,3}$` removes anywhere on the page.
