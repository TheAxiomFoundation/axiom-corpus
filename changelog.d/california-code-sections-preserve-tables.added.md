`extract-california-code-sections --preserve-tables` renders each LegInfo table row as one `cell | cell` line, emits a paragraph-wrapped table once, and drops no block for repeating earlier text. The default path's block dedup drops repeated cells, row labels and whole paragraphs (16 records in three merged us-ca scopes, including R&TC 17052(b)); it stays the default so existing scopes rerun unchanged.
