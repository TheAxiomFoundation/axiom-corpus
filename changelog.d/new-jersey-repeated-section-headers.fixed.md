Keep every block of New Jersey statute text when the Legislature's bulk file prints the same section header twice. The adapter used to drop a later block entirely (N.J.S.A. 34:15C-10.5, printed as "34:15C-10.") or replace a section's current text with a stale second copy (N.J.S.A. 34:16-43). Each later block is now its own provision under the repository's same-number variant path (`<section>--variant-N`), with `variant` and `canonical_citation_path` metadata and a `new_jersey:variant` identifier, and the first block lists its variants in `variant_citation_paths`. A header the publisher reprints partway through one section (N.J.S.A. 52:27D-18.5) stays part of that section.
