Keep an Arizona, Illinois or New York statute section whose fetched page names no section (a maintenance, empty or wrong-shape page) as an inventory gap with no provision, sourced from that page, so coverage and strict release validation report the run as incomplete. Before, the Arizona parser wrote such a page as a section with no text, the Illinois parser wrote it as the section's text under the document's own citation, and New York's Senate-page crawl wrote it as a container with no text, so coverage read complete. Arizona now requires the page title or first paragraph to name a section, Illinois requires a page without an ILCS citation to open a line with its own section's heading, and New York requires a page reached through a "SECTION ..." link to parse as a section; the crawl no longer follows links from a page that fails that check, which also stops it from looping forever when that page links back to the page that listed the section. The extractors still write a section whose official page names it but holds no text or marks it repealed, and a run with no failures writes the same artifacts as before.
