State statute extractors now keep a section they cannot fetch or read as an inventory gap with no provision, in Maryland and Massachusetts. Before, such a section was logged as an error and dropped from the inventory, so coverage and release validation still read the run as complete. The gap points at the section's own page when it was fetched but unusable (a maintenance, empty or wrong-shape page), or at the listing that names it when it could not be fetched. A section whose official page holds no text, or marks it repealed, is still written, and the run stays complete.
