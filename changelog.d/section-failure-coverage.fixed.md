Keep an Arizona, Hawaii, Idaho, Illinois, Iowa, Maryland, Massachusetts, Montana, New York or West Virginia statute section, or a NYC Administrative Code section, that the extractor cannot fetch or read as an inventory gap with no provision, so coverage and strict release validation report the run as incomplete instead of reading it as complete. Before, the extractor logged such a section as an error and dropped it from the inventory (West Virginia wrote it as a provision with no text). The gap points at the section's own page when the run fetched it but could not use it (a maintenance, empty or wrong-shape page), and at the listing that names the section when the run could not fetch it. New York's Senate-page crawl does the same for a law or container page it cannot fetch, and Iowa now rejects a section file that is not a PDF instead of reading a maintenance page as section text. Some cases fail the whole run instead, because no fetched listing names the section: a section that the targeted New York OpenLegislation run or the NYC Administrative Code run cannot fetch, and, as before, a Montana section page the run cannot fetch. The extractor still writes a section whose official page holds no text or marks it repealed, and a run with no failures writes the same artifacts as before.
