PDF OCR reads a page scanned sideways or upside down upright (`ocr_orientation`, on by default): Tesseract's orientation detection runs first, a page it finds upright or cannot judge is read exactly as before, and a turned read replaces the read as rendered only when it reads better. Tesseract read the sideways training slides in the Utah 14-0007-MM and 14-0004-MM approval documents as upside-down text.
