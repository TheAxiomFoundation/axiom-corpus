The official-document HTML extractor now reads `pre` elements as text nodes and keeps their line breaks. Before, text printed in a `pre` reached a row only inside a `p`, `li`, `table` or `blockquote`, through a manifest's `html_text_selector`, or through the root fallback of a page with no other text node, so preformatted exhibits such as the SSA POMS screen printouts were left out of provision rows. A page whose only text nodes are `pre` still takes the root fallback, now with `pre` line breaks. Released scopes are unchanged; `scripts/audit_html_pre_gap.py` measures what re-extracting each locked scope would change.
