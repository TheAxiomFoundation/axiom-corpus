CI installs from `uv.lock` (`.github/scripts/install-locked.sh`: `uv export --frozen`, then `pip install --require-hashes`) instead of resolving `pyproject.toml`'s lower bounds with pip, so tests, the corpus guard and the release validators run on the versions `uv run` uses locally. On 2026-10-13 the `test (3.14)` job had 82 of its 122 packages at a version other than the lock's, PyMuPDF among them (1.28.2 against 1.26.7), and the two tests that re-extract committed PDFs under PyMuPDF 1.26.7 never ran in CI. The `dev` extra gains `pytest-cov`, `pytest-timeout` and `pytest-xdist`, which CI used to install by name. The lock moves `pyiceberg` 0.10.0 to 0.12.0 (and adds `zstandard`), because 0.10.0 has no wheel for Python 3.14 and would be compiled on every CI job; nothing else in the lock moves. See `docs/dependency-lock.md`.
