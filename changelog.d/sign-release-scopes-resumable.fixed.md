`scripts/sign_release_scopes.sh` can now be re-run with the same command after any failure, with nothing to clean up by hand. Step 1 checks every unreleased scope's coverage and artifacts before it stages any, and stages them all in one `git add`. An incomplete or missing scope no longer leaves the scopes before it staged, which stopped the next run at "tracked tree is dirty". A run that stops before the selector commit, because a step failed or the run was interrupted, unstages what it staged and deletes its copy of `manifests/releases/<name>.json`. A failed `validate-release` therefore no longer leaves an untracked selector behind for the next run to refuse with "already exists; selectors are immutable". The script asks for `AXIOM_CORPUS_INGEST_PRIVATE_KEY` only when some unreleased scope has no signed ingest manifest yet, and still before it stages anything.
