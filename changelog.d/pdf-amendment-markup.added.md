Add three opt-in PDF extraction keys for official-document manifests: `amendment_markup` writes struck-through text as `[-deleted-]` and underlined text as `{+inserted+}` (GNU wdiff delimiters) and records the notation in each marked page's metadata; `sort_blocks` reads a boxed note drawn last in the content stream where it is printed; `ignore_actual_text` extracts visible text that an empty `/ActualText` tag would hide. Without the keys PDF extraction is unchanged. The CDSS ACL 06-31 and 13 DE Reg. 1550 scopes use them, which restores the letter's page-1 "Changes include:" paragraph, marks the deleted and inserted rule text, and keeps Delaware's boxed exceptions with the items they qualify.
