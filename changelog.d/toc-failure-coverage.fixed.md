Keep a Maine or Ohio title or chapter whose table of contents yields no children as an inventory gap with no provision. Coverage, strict release validation and the completion selector then report the run as incomplete, instead of the sections under the container silently disappearing.

A gap's source depends on how the page failed. A page that could not be read is sourced from the parent listing that names it. A page that was read but is a maintenance, empty or wrong-shape page, or lists nothing, is sourced from that page itself. In each adapter:

- **Maine titles and chapters:** any fetch failure is a gap. This includes a download error and a missing `--source-dir` file.
- **Ohio titles:** a download error or an unreadable `--source-dir` file is a gap. Before this, a title fetch failure aborted the run.
- **Ohio chapters:** a download error was already a gap and still is. A missing `--source-dir` chapter file still aborts the run.
