`sign-ingest-manifest` now writes the signed manifest to a temporary file in the same directory, fsyncs it and renames it into place, so a signing process that is interrupted (Ctrl-C), killed or crashes mid-write, or whose write fails (a full disk), leaves no truncated manifest at `.axiom/ingest-manifests/<jurisdiction>/<class>/<version>.json`. `scripts/sign_release_scopes.sh` keeps any manifest that already exists, so a partial one would otherwise have been committed on the next run. The new helper, `write_bytes_atomically`, is the temp-file-and-rename sequence `write_lock` had inline; lock files now go through it too and are fsynced as well. `.gitignore` keeps the temporary file a killed write can leave (`.axiom/**/.*.tmp`) out of commits.
