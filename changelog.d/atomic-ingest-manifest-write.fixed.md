`sign-ingest-manifest` now writes the signed manifest to a temporary file in the same directory, fsyncs it and renames it into place, so an interrupted or failed write (Ctrl-C, a full disk, a crash) leaves no truncated manifest at `.axiom/ingest-manifests/<jurisdiction>/<class>/<version>.json`. `scripts/sign_release_scopes.sh` keeps any manifest that already exists, so a partial one would otherwise have been committed on the next run. Lock files go through the same helper (`write_bytes_atomically`, which `write_lock` used inline), now fsynced too, and `.gitignore` keeps the temporary file of a killed write (`.axiom/**/.*.tmp`) out of commits.
