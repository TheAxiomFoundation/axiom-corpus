Keep an Alaska, Arizona, Connecticut, Delaware, Florida, Hawaii, Iowa, Kansas or Louisiana statute container whose table of contents cannot be fetched, is a maintenance or empty page, or lists no children as an inventory gap with no provision, so coverage and strict release validation report the run as incomplete instead of silently dropping every section under it. Two cases keep their old behaviour: a Florida title index page that cannot be fetched still stops the run, because Florida's titles come from a fixed list rather than a fetched index page; and Connecticut's annual supplement set is unchanged, so only the current set records these gaps.
