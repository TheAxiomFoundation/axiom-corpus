`sign-ingest-manifest` no longer records a path on the signing machine in a signed manifest. Fourteen manifests on `main` recorded the build command verbatim, publishing paths such as `/Users/<name>/...`, `/private/tmp/...` and `/tmp/...` in `command.text`.

`build_ingest_manifest` now records absolute paths inside the checkout repository-relative and refuses any other local path, naming it. "Inside the checkout" covers spellings through `~`, `$HOME`, `-o`/`@` leads and symbolic links, and a checkout path containing a space. A path is rewritten only where the shell word, read with its quoting, still names the same file, so `"<checkout>"-backup` is refused rather than recorded as `"."-backup`. Nothing is rewritten where the shell would compute the name (a `$`, glob, brace or backslash in the word, or a quoted `~`). A `:` separates entries only in `*PATH` and `*DIRS` variables.

Local roots are matched in any case and however spelled (`//Users`, `/./private`, `/var/../tmp`). Commands are read both as written and with their quotes, escapes and line continuations removed (`/U\sers`, `/U'se'rs`). A `$VAR` in front of a root does not hide it, `$TMPDIR/` counts like `$HOME/`, and any `file:` URL is refused.

A path inside a source URL argument is left alone, since the source dictates the URL. Whitespace, an unquoted shell operator or a command substitution ends that exemption, so `https://x.gov/a>/tmp/out` and `"https://x.gov/?q=$(cat </tmp/x)"` are still read.

`sign_ingest_manifest` refuses a manifest that records a local path in any string field, the `--key-id` included. Only the real `signature.value` node, which is base64, is skipped. `sign-ingest-manifest` reports the refusal and exits 2 with nothing signed. `scripts/recover_ingest.py` records a fetched directory outside the checkout as `<fetched-dir>`.

`tests/test_ingest_manifest_local_paths.py` fails CI on any manifest under `.axiom/ingest-manifests/` that records a local path, unless `.axiom/ingest-manifest-local-paths.yaml` grandfathers it. Each entry pins the manifest's path, bytes and fields, stale entries fail, and no entry can be added. The fourteen are listed there until the hub scrubs and re-signs them (axiom-corpus#896).
