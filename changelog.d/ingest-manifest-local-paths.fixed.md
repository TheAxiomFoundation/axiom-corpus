`sign-ingest-manifest` no longer records a path on the signing machine in a signed manifest. Fourteen manifests on `main` recorded the build command verbatim, publishing paths such as `/Users/<name>/...`, `/private/tmp/...` and `/tmp/...` in `command.text`. `build_ingest_manifest` now records absolute paths inside the checkout repository-relative, through `~`, `$HOME` and symbolic-link spellings, and refuses any other local path, naming it. `sign_ingest_manifest` refuses a manifest that records one in any string field. `sign-ingest-manifest` reports the refusal and exits 2 with nothing signed. `scripts/recover_ingest.py` records a fetched directory outside the checkout as `<fetched-dir>`.

`tests/test_ingest_manifest_local_paths.py` fails CI on any manifest under `.axiom/ingest-manifests/` that records a local path, unless `.axiom/ingest-manifest-local-paths.yaml` grandfathers it. Each entry pins the manifest's bytes and fields, stale entries fail, and no entry can be added. The fourteen are listed there until the hub scrubs and re-signs them (axiom-corpus#896).
