Activation and its preview can run over a direct database connection. Cloudflare fronts the Supabase Management API with a 120 s proxy read timeout (error 524, run 34879466018), so even with the statement timeout disabled the API cannot carry the transaction that verifies and repoints 800+ scopes; the transaction itself completed server-side while the client was cut off. When the `SUPABASE_DB_URL` secret (the project's session-pooler connection string) is present, `scripts/activate_release.py` and `scripts/check_release_gate.py` run the same `corpus.activate_corpus_release` / `preview_corpus_release_activation` functions over psycopg2 with the session statement timeout disabled, after checking that the URL names the expected project; without it they fall back to the Management API.
