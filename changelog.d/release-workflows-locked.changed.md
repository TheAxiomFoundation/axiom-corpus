The release workflows (`publish.yml`, `activate-release.yml`, `register-release-object.yml` and `mirror-release.yml`) install from `uv.lock` through `.github/scripts/install-locked.sh`, so releases are signed, published, registered, mirrored and activated on the hash-checked versions CI tests; `mirror-release.yml` drops its separate `boto3==1.40.11` pin for the lock's boto3 1.42.17.
