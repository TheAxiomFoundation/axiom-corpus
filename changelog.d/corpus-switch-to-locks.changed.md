Corpus bytes leave git. Every protected file under `data/corpus/{sources,inventory,provisions,coverage}` (55,269 files, 14.9 GB) moves into one lock file per scope under `.axiom/corpus-locks/` (1,903 lock files), pinned by sha256 and served from R2 `objects/sha256/`. `axiom-corpus-ingest corpus fetch` places what a task reads; see `docs/corpus-storage.md`. History is not rewritten, so every earlier commit keeps its files.
