A `drop_lines` or `drop_line_patterns` entry that matches a bare number (a line of digits only, such as `^\d{1,3}$` written for page numbers) now drops that line only from the page's margin: when no line the filters keep shares its row, and every kept line on the page lies below it, or every one lies above it. Table cells, list numbers and citation titles that are bare numbers stay in the text, where the content-only filter removed them from released rows (Colorado Works §§ 3.606.1 and 3.609.2, Colorado Rule 39-22-2003, Delaware 16 DE Admin. Code 3000, 4000 and 9000). A bare number the page cannot place, OCR text or text that does not run left to right, is dropped as before. Existing scopes do not change until their documents are extracted again.
