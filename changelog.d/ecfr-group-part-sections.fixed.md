Read eCFR sections that are numbered for a part other than the one holding them: 2,981 live sections on 2026-10-08, nearly all in 43 CFR, where subpart 3809 of part 3800 holds § 3809.1 and eCFR has no part 3809. Such a section keeps its citation path (`us/regulation/43/3809/1`), but a run scoped to part 3800 now includes it instead of dropping it. Its inventory parent is now the subpart that holds it (`us/regulation/43/3800/subpart-3809`), not `us/regulation/43/3809/subpart-3809`, which no inventory holds. Its source URL is on part 3800's eCFR page rather than a missing part-3809 page, and `metadata.enclosing_part` records part 3800. Two eCFR provisions can no longer share a citation path silently: an inventory with two items under one path fails, a retained XML whose `--section` selector names two sections fails before writing, and a run whose XML holds two elements under one path reports a title error instead of keeping the later one.
