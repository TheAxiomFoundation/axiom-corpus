Such a section keeps its citation path (`us/regulation/43/3809/1`), but a run scoped to part 3800 now includes it instead of dropping it. Its inventory parent is now the subpart that holds it (`us/regulation/43/3800/subpart-3809`), not `us/regulation/43/3809/subpart-3809`, which no inventory holds. Its source URL is on part 3800's eCFR page rather than a missing part-3809 page, and `metadata.enclosing_part` records part 3800. An eCFR inventory that would put two items under one citation path now fails instead of writing both.
