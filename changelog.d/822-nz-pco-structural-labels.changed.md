NZ PCO provision bodies print subsection, paragraph and item labels as legislation.govt.nz publishes them: a label marked `denominator="yes"` in parentheses, on the same line as its text (`(1) A person is entitled…`, `(a) the person is receiving…`), where extractions wrote it bare on a line of its own (`1\nA person is entitled…`). A label the publisher prints as written stays as written, an empty label prints nothing, and schedule definition rows print their paragraph labels the same way. Each block now starts its own line, so table rows whose first cell opens with `(` are no longer run together. Existing scopes do not change until NZ legislation is extracted again; that extraction changes the verbatim text of most NZ provision rows. `axiom_corpus.converters.nz_pco.bare_structural_labels()` replays the bare layout, and the amendment-marker reproducer and the release-row tests use it to re-extract scopes made with it byte for byte.
