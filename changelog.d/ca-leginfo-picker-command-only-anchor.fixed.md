California LegInfo picker parsing now treats an anchor as a version link when any of its attributes carries a row-indexed picker command (`selectFromMultiples:j_idt139:1:j_idt141`), as well as when it has the `portletNav` class or names an `op_*` submission field. Before, an anchor without the class whose handler carried only the command was skipped, so a picker with another valid link gave `coverage.complete=True` with that version missing. Such an anchor now raises, like other malformed version links. Navigation commands without a row index (`selectFromMultiples:addMyFavTitle`) are still ignored, and the four retained pickers still give all nine versions.
