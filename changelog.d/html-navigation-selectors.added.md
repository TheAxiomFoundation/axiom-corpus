Official-document manifests can name a publisher's page navigation: `html_navigation_selectors` drop a positional block whose every string lies inside a matched element (a tab or jump link), and `html_navigation_heading_selectors` drop the block a matched heading starts (a "Related Policy" list). The block is dropped whole and its ordinal is used up, so no other block changes path or text; `html_drop_selectors` cannot do this on positional pages, because a block they empty renumbers every block after it. The Washington DSHS EA-Z manifest declares its "Clarifying Information" / "Worker Responsibilities" jump links, and the Texas Works, MEPD and C-120 manifests (and their builders) the "Related Policy" lists. Existing scopes do not change; re-extracting the four scopes from their locked bytes, successors would drop 994 more rows (403 of them flagged `navigation_body` rows; `navigation_body` falls from 504 to 14) with no other row's path or text changed and no new content-check finding (`docs/ingest-runs/2026-10-13-html-navigation-selectors.md`).
